# Third-party character resources

Roger incorporates adapted anatomy from **Realistic Human Base Mesh** by **Julien Kaspar / Blender Studio**, licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). [Original asset page](https://studio.blender.org/training/realistic-human-research/use-of-base-meshes/). Head, neck, eyes and hands were extracted, reshaped, mapped to the project’s original generated face, fitted and bound to the game rig. No endorsement by the source author is implied.

Roger’s jacket and satchel use **Fabric030** and **Leather030** by **Lennart Demes / ambientCG**, released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). [Fabric030](https://ambientcg.com/view?id=Fabric030), [Leather030](https://ambientcg.com/view?id=Leather030), [license information](https://docs.ambientcg.com/license/). Physical UV scale, material tint, normal intensity and delivery encoding were adapted.

Original retained files are byte-for-byte verified by `provenance.json`. The application must retain the Blender Studio attribution and license link in its credits.

Roger’s fitted short hair uses **Short02** from **MakeHuman system assets** (Data Collection AB, Joel Palmius, Jonas Hauquier), explicitly released under **CC0 1.0** in September 2020. [Official asset and license listing](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html). Coordinate conversion, cranial fit, rig binding, one subdivision level and PBR rendering were adapted. Five original overlapping locks were fitted to the groom and mapped to its existing strand atlas; the original strand UV and alpha atlas are retained. The retained OBJ and material headers include the original license declaration.
